# ZonaFit POS

Aplicación de punto de venta con interfaz en React y Vite, preparada para ejecutarse como aplicación de escritorio con Electron.

## Tecnologías

- JavaScript
- React
- Vite
- Electron
- Supabase y SQLite (dependencias incluidas en el proyecto)

## Requisitos

- Node.js y npm

## Instalación y ejecución

```bash
npm install
npm run dev
```

Para generar la compilación de producción:

```bash
npm run build
```

Para iniciar la aplicación de escritorio:

```bash
npm start
```

## Estructura

- `src/`: interfaz y lógica de la aplicación
- `electron/`: proceso principal y configuración de escritorio
- `public/`: recursos estáticos
- `tests/`: pruebas
- `docs/`: documentación del proyecto

Consulta los archivos de `docs/` para información adicional sobre configuración y uso.
